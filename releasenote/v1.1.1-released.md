## 変更概要

- エージェントによる開発フローの品質標準化と自動化を強化するため、コミットメッセージおよび Git 運用規約（`.agents/rules/git-workflow.md`）を新設しました。
- `develop` ブランチ向けプルリクエスト（PR）のタイトル・説明文を標準フォーマットで生成するスキル（`.agents/skills/create-pr/`）を新設しました。
- 機能追加や設定変更時に `README.md` や `configs/config.example.yaml` を同期更新するためのドキュメント保守規約（`.agents/rules/documentation.md`）を新設しました。
- `.agents/AGENTS.md` の基本開発規約を拡充し、新設されたルールとスキルの参照を追加しました。

## 破壊的変更（互換性への影響）

- なし（既存の Go ソースコードや CLI バイナリの挙動への影響はありません）。

## 変更詳細

### 1. Git 運用およびコミット規約の策定

- [.agents/rules/git-workflow.md](file:///home/skyou/workspace/devctl/.agents/rules/git-workflow.md):
  - ブランチ運用モデル（`develop` 起点、`feature/*`, `fix/*`, `release/*`）を定義。
  - コミットメッセージのフォーマット（Prefix `feat:`, `fix:`, `docs:`, `chore:`、対象バージョン `(vX.Y.Z)`、日本語箇条書き、`closes #XX`）を明文化。
  - コミットメッセージおよび PR は原則「日本語」で記載するルールを確立。

### 2. プルリクエスト（PR）生成スキルの新設

- [.agents/skills/create-pr/SKILL.md](file:///home/skyou/workspace/devctl/.agents/skills/create-pr/SKILL.md):
  - 実装・検証が完了したブランチから、plan/released ファイルとコミットログを解析して develop 向けの PR タイトル・本文を自動生成する実行手順書。
- [.agents/skills/create-pr/resources/pr-template.md](file:///home/skyou/workspace/devctl/.agents/skills/create-pr/resources/pr-template.md):
  - 概要、主な変更点、関連Issue、破壊的変更、動作確認ログを含む PR 標準テンプレート。

### 3. ドキュメント作成・保守規約の策定

- [.agents/rules/documentation.md](file:///home/skyou/workspace/devctl/.agents/rules/documentation.md):
  - コード変更とドキュメントの完全同時更新を基本原則として定義。
  - `README.md` 更新基準（主な特徴、Usageコードブロック、引用ノート補足）。
  - `configs/config.example.yaml` 更新基準（コメント、デフォルト値、CLI 機能との連携案内）。
  - `releasenote/ideas-*.md` の将来アイデア起票フォーマットを標準化。

### 4. エージェント開発規約の更新

- [.agents/AGENTS.md](file:///home/skyou/workspace/devctl/.agents/AGENTS.md):
  - 基本開発規約に新設されたルール（`git-workflow.md`, `documentation.md`）およびスキル（`create-pr/SKILL.md`）の参照を追加。
