## 変更の目的・背景

エージェント開発環境の標準化および自律作業品質の向上を目的として、コミットメッセージ・Git運用規約、PR作成スキル、およびドキュメント作成・保守規約を整備する。
エージェントがコミットやPRを作成する際の言語（日本語）・書式・ブランチ命名規則を明文化し、PRタイトル・本文の生成手順をスキルとして定型化する。
また、機能追加時に `README.md` や `configs/config.example.yaml` を同期更新するドキュメント保守ルールを策定し、ドキュメントの陳腐化や更新漏れを恒久的に防止する。

---

## 開発・ブランチ運用方針

- **作業ブランチ**:
  - `develop` ブランチから機能開発用ブランチ `feature/agent-rules-and-skills` を新設して作業を行うこと。
  - 実装および検証（`verify.sh`）完了後、リリースノート（`v1.1.1-released.md`）を作成し、`develop` へのマージ準備を整える。

---

## 要求仕様一覧

- [x] 要求項目1: コミットメッセージおよびGit運用規約の策定（Rules: `.agents/rules/git-workflow.md`）
  - ブランチ命名規則（`feature/<機能名>`, `release/<バージョン>`, `fix/<課題名>` 等）の定義。
  - コミットメッセージの書式（Prefix `feat:`, `fix:`, `docs:`, `chore:`、対象バージョン `(vX.Y.Z)`、日本語による変更点箇条書き、`closes #XX` 等）の明文化。
  - コミットメッセージおよび PR は原則「日本語」で記載することのルール化。
- [x] 要求項目2: PR作成スキルの新設（Skills: `.agents/skills/create-pr/`）
  - `.agents/skills/create-pr/SKILL.md`: planファイルおよび直近のコミットログ・差分を読み解き、develop向けのPRタイトル・本文を生成する手順書。
  - `.agents/skills/create-pr/resources/pr-template.md`: 概要、主な変更点、関連Issue、破壊的変更、検証結果を含むPR標準テンプレートの配置。
- [x] 要求項目3: ドキュメント作成・保守規約の策定（Rules: `.agents/rules/documentation.md`）
  - コマンド追加・修正時の `README.md` 同期更新ルール（コマンド構文、使用例、オプション一覧表、カレントディレクトリ自動判定の記述）。
  - 設定項目・タスク変更時の `configs/config.example.yaml` 同期更新ルール（コメント・ベストプラクティス追記）。
  - 将来構想・アイデア起票時の `releasenote/ideas-<機能名>.md` の書式ルール。
- [x] 要求項目4: `.agents/AGENTS.md` の更新と全体整合性の確保
  - 基本開発規約に新設ルール（`git-workflow.md`, `documentation.md`）およびスキル（`create-pr`）の参照を追加する。
