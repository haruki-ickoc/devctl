## 変更の目的・背景

GitHub Issue #2（`projectのstart / stopを基本機能に追加してほしい`）への対応。
現行（v1.1.1）の `devctl` では、コンテナの作成・起動を行う `up` と、コンテナの停止・破棄（削除）を行う `down` は提供されているが、**コンテナを破棄せずに一時停止する `stop` および停止済みコンテナをそのまま高速再開する `start`** が存在しない。
複数プロジェクト並行開発時のメモリ・CPU リソース節約や、特定マイクロサービス・ワーカーのみの個別一時停止・再開ニーズに応えるため、`start` / `stop` をネイティブのプロジェクト操作コマンドとして追加する。

## 要求仕様一覧

- [x] 要求項目1: `internal/docker/compose.go` への `Start` および `Stop` メソッド追加
  - `ComposeClient.Start(opts ComposeOptions) error` を追加する（`docker compose ... start [services...]`）。
  - `ComposeClient.Stop(opts ComposeOptions) error` を追加する（`docker compose ... stop [services...]`）。
  - ランナー層（`c.runner.RunCommand`）を経由して実行し、`--dry-run` プレビューおよび失敗時のエラー伝播に完全対応する。
- [x] 要求項目2: `internal/cmd/project.go` への `start` / `stop` サブコマンドおよびトップレベル短縮コマンドの実装
  - `devctl project start [project-name] [services...] [flags]` および短縮エイリアス `devctl start` を新設する。
  - `devctl project stop [project-name] [services...] [flags]` および短縮エイリアス `devctl stop` を新設する。
  - `resolveTargetProject` により、プロジェクト名引数およびカレントディレクトリからの自動検出に対応する。
  - 引数でサービス名（`services...`）が指定された場合は、該当サービスのみを対象に開始・停止を実行可能とする。
  - `-f` / `--file` フラグによるカスタム Compose ファイル指定に対応する。
  - `start` 失敗時には、コンテナ未作成の可能性を考慮し「初回起動時は `devctl up` を実行してください」という解決策のヒントを提示する。
- [x] 要求項目3: 単体テスト・自動検証の拡充
  - `internal/docker/compose_test.go` に `Start` および `Stop` メソッドの単体テストを追加する。
  - `internal/cmd/project_test.go` に `start` / `stop` コマンドの登録確認、フラグ確認、および DryRun 実行テストを追加する。
  - `go vet ./...` および `go test ./...` を実行し、警告・エラーが 0 件であることを確認する。
- [x] 要求項目4: ドキュメントおよび設定例の同期更新（`documentation.md` 準拠）
  - `README.md` の「プロジェクト操作」セクションに `devctl start` / `devctl stop` の使用例（プロジェクト全体およびサービス個別指定）を追記し、`up` / `down` との使い分けを補足する。
  - `configs/config.example.yaml` のコメントに `start` / `stop` を反映する。

## 技術的制約および互換性

- **破壊的変更の許容**: なし（既存の `up`, `down`, `restart`, `build` 等の挙動および `config.yaml` の互換性を完全に維持すること）。
- **ランナー層の経由**: 外部コマンドの実行は必ず `internal/docker/runner.go` を経由し、`--dry-run` に対応させること。
- **外部パッケージの追加**: 原則不可（標準ライブラリおよび既存の Cobra パッケージの範囲で実装すること）。
- **コーディング規約**: インデントは半角スペース4文字を順守し、`CGO_ENABLED=0` による静的リンク性を維持すること。
