## 変更概要

- `examples/sample/` 配下に、マルチネットワーク構成（プロジェクト個別固定 IP サブネット + 共通基盤ネットワーク）を実証するサンプルプロジェクト環境（PHP/Laravel + MySQL + Traefik/DBGate 連携）を構築。
- `README.md` に「共通基盤 DBGate から各プロジェクト DB への接続設定」セクションを追加し、Docker 内部 DNS エイリアスを活用した接続設定手順およびポート競合防止のメリットを明記。
- 設定ファイル例（`configs/config.example.yaml`）を更新し、`dbgate` の解説コメントおよび `sample` プロジェクトのカスタムタスク（`migrate`, `seed`, `test`, `bash`）を実環境に合わせて拡充。

## 破壊的変更（互換性への影響）

- なし（CLI バイナリの既存挙動や互換性への影響はありません。サンプルの追加およびドキュメント・設定例の整備です）。

## 変更詳細

### 1. サンプルプロジェクト環境の構築 (`examples/sample/`)

devctl によるマルチプロジェクト・マルチネットワーク運用を直感的に体験できるリファレンス実装を追加しました。

- **`compose.yml`**:
  - `sample-network`（固有サブネット: `10.11.0.0/24`、固定 IP 割り当て）と `core-network`（共通基盤連携、外部ネットワーク）の共存構成。
  - `db` サービスに `aliases: - sample-db` を指定し、共通基盤から安全にアクセス可能。
  - `app` サービスに Traefik のルーティングラベル（`Host("sample.localhost")`）を設定。
- **`_docker/`**:
  - `images/app/Dockerfile`: PHP 8.2 + Apache + Composer
  - `images/db/Dockerfile`: MySQL 8.0 + my.cnf
  - `entrypoints/app.sh`: DB 接続待機およびマイグレーション自動実行スクリプト
  - `.env`, `.env.example`: 環境変数ひな形
- **`public/index.php`**:
  - アプリケーション稼働状況および DB 接続テストが即座に確認できる軽量ダッシュボード。
- **`README.md`**:
  - サンプルの構成図（Mermaid）、ネットワーク設計、devctl による起動手順をまとめたドキュメント。

### 2. 共通基盤 DBGate からの接続設定ガイド (`README.md`)

- Core サービスとして動作する DBGate（`http://dbgate.localhost`）から、ホスト側のポートフォワード（`3306:3306` 等）を介さずに、Docker 共通ネットワーク経由で各プロジェクトの DB コンテナへ直接接続する設定手順を整備。
- ホスト名に DNS エイリアス（`sample-db`）、ポートに内部ポート `3306` を指定することで、複数プロジェクト間でのポート競合を防止する運用ベストプラクティスを解説。

### 3. 設定ファイル例の拡充 (`configs/config.example.yaml`)

- `core.services.dbgate` の説明にプロジェクト DB への接続案内を追記。
- `projects.sample` に `dbgate` への前提依存（`depends_on.core`）および日常開発で有用なタスク（`migrate`, `seed`, `test`, `bash`）を追加。
