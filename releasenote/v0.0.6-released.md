## 変更概要

- `NetworkManager.InspectIPAM` を実装し、既存 Docker ネットワークの Subnet および Gateway 情報を取得可能に改修。
- `devctl core up`、`devctl project up`、`devctl network create` でのネットワーク自動担保時（`Ensure`）に、設定ファイル（`config.yaml`）と実環境のネットワーク構成（Subnet / Gateway）に差異がある場合、警告と対処法（`devctl network rm` の案内）を表示する機能を追加。
- `devctl network check` コマンドを強化し、共通ネットワークの存在確認に加えて実環境の IPAM 構成および設定値との一致状況を診断表示するように改善。
- `README.md` に「固定 IP（Static IP）環境の設定ガイドと検証手順」セクションを追加し、プロジェクト側の `compose.yml` 定義例や動作確認手順を整備。

## 破壊的変更（互換性への影響）

- なし
  - 設定差異が検知された場合でも警告メッセージの出力にとどまり、既存ネットワークの自動削除や強制的な設定変更は行いません。
  - Subnet / Gateway を指定していない既存環境への動作影響はありません。

## 変更詳細

### 1. 既存ネットワークの Subnet / Gateway 設定差異の検知・警告機能

- **`InspectIPAM` メソッドの実装 (`internal/docker/network.go`)**:
  `docker network inspect` から IPAM Config（Subnet および Gateway）を安全にパースして取得する処理を追加。`--dry-run` にも対応。
- **`Ensure` での差異検知と警告 (`internal/docker/network.go`)**:
  ネットワークが既に存在している場合、設定ファイルで `subnet` または `gateway` が定義されていれば実環境の値と比較。不一致があれば警告アイコン（▲）とともに差異内容と安全な再作成手順を出力。
- **`devctl network check` の表示強化 (`internal/cmd/network.go`)**:
  ネットワーク存在時に実環境の Subnet / Gateway を表示し、設定ファイルに指定がある場合は一致・不一致の診断結果を即座に確認可能に改修。

### 2. 固定 IP 設定ガイドおよび検証手順の整備 (`README.md`)

- `config.yaml` における共通ネットワークの Subnet / Gateway 定義例。
- 各プロジェクトの `compose.yml` での記述方法（`networks.<name>.external: true` および `ipv4_address` 指定）。
- `devctl network check` による事前診断手順。
- コンテナ起動後の IP アドレス確認コマンド（`docker inspect` 例）。
- 設定不一致時のトラブルシューティング（`devctl network rm` からの再作成手順）。

### 2. devctl network check による整合性診断結果

#### 設定値と実環境が一致している場合:

```bash
$ ./bin/devctl network check -c config-match.yaml
ℹ ネットワークを確認中: bridge
✔ ネットワーク 'bridge' は存在します。
ℹ   実環境構成: Subnet=172.17.0.0/16, Gateway=172.17.0.1
ℹ   設定ファイル: Subnet=172.17.0.0/16, Gateway=172.17.0.1
✔   Subnet / Gateway の設定は正常に一致しています。
```

#### 設定値と実環境に差異がある場合:

```bash
$ ./bin/devctl network check -c config-mismatch.yaml
ℹ ネットワークを確認中: bridge
✔ ネットワーク 'bridge' は存在します。
ℹ   実環境構成: Subnet=172.17.0.0/16, Gateway=172.17.0.1
ℹ   設定ファイル: Subnet=192.168.10.0/24, Gateway=192.168.10.1
▲ ▲ 警告: 設定ファイルと実環境のネットワーク構成が一致していません:
▲     - Subnet (設定: 192.168.10.0/24, 実環境: 172.17.0.0/16)
▲     - Gateway (設定: 192.168.10.1, 実環境: 172.17.0.1)
▲   再作成する場合は 'devctl network rm' を実行後に 'devctl network create' を実行してください。
```

### 3. Ensure 実行時の差異警告

```bash
$ ./bin/devctl network create -c config-mismatch.yaml
✔ ネットワーク 'bridge' は既に存在します。
▲ ▲ 警告: 既存ネットワーク 'bridge' の構成が config.yaml の設定と一致していません:
▲     - Subnet (設定: 192.168.10.0/24, 実環境: 172.17.0.0/16)
▲     - Gateway (設定: 192.168.10.1, 実環境: 172.17.0.1)
▲   固定IPの競合や接続エラーを防ぐため、再作成する場合は 'devctl network rm' を実行してから再度起動してください。
```
