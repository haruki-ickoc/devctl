## 変更の目的・背景

ユーザーがビルド環境（Go や make）を持っていなくても、単一バイナリを手軽にダウンロード・インストールして即座に利用できるようにするため、GitHub Releases を活用した自動クロスコンパイル・バイナリ配布基盤と、環境自動判別ワンライナーインストールスクリプト（`scripts/install.sh`）を導入する。

## 要求仕様一覧

- [x] 要求項目1: GitHub Actions による自動リリースワークフローの構築 (`.github/workflows/release.yml`)
  - バージョンタグ（`v*.*.*`）の push をトリガーとして起動。
  - 主要プラットフォーム（Linux amd64/arm64, macOS amd64/arm64, Windows amd64）向けにクロスコンパイルを実行。
  - バージョン埋め込みフラグ（`-ldflags`）を適用した単一バイナリおよびチェックサム（SHA256）を生成。
  - GitHub Releases への自動アセットアップロードとリリース作成。
- [x] 要求項目2: ワンライナー・インストールスクリプトの作成 (`scripts/install.sh`)
  - 実行環境の OS（Linux / macOS）および CPU アーキテクチャ（amd64 / arm64）を自動判別。
  - GitHub Releases の最新（または指定版）から適切なバイナリを安全にダウンロード。
  - `~/.local/bin/devctl` への配置、実行権限（`chmod +x`）の付与、PATH 確認メッセージの表示。
- [x] 要求項目3: `README.md` のインストールガイドの刷新
  - ワンライナー（`curl -fsSL ... | bash`）によるインストール手順を最優先で案内。
  - GitHub Releases からの直接ダウンロードおよび手動配置手順を追記。

## 変更対象の想定範囲

- `.github/workflows/release.yml`
- `scripts/install.sh`
- `README.md`

## 技術的制約および互換性

- `CGO_ENABLED=0` による静的リンクを維持し、外部依存ライブラリ不要な単一バイナリを生成すること。
- インストールスクリプトは `bash`、`curl`（または `wget`）、`tar` の標準コマンドのみで動作し、root 権限（sudo）を要求せずユーザーディレクトリ（`~/.local/bin`）へ安全にインストールすること。
- インデント規約: 半角スペース4文字を順守すること。
