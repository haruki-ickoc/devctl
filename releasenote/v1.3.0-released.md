## 変更概要

- GitHub Issue #4（`プロジェクト起動時の共通基盤の生存検証・自動起動`）に対応し、プロジェクトの `depends_on.core` に指定された共通基盤サービスについて、稼働状態（`running`）を事前検証する機能を実装しました（方式A：明示指定型）。
- 指定されたすべての共通基盤サービスが稼働中の場合は `docker compose up -d` をスキップし、停止中（未起動）のサービスが存在する場合のみ、不足しているサービスに限定して自動起動（`docker compose up -d`）を実行します。
- 共通ネットワークおよび共通基盤の事前検証（`prepareDependencies`）の適用範囲を、従来の `up` だけでなく `start` および `restart` にも拡大しました。これにより、PC 再起動後などに `devctl start` や `devctl restart` を実行した際も、自動的に共通ネットワークと共通基盤の生存が保証されます。
- 単体テストの拡充、設定例およびドキュメントの同期更新を実施しました。

## 破壊的変更（互換性への影響）

- なし（既存の `config.yaml` の `depends_on` 構文や CLI 引数の互換性を完全に維持しています）。

## 変更詳細

### 1. `internal/docker/compose.go` へのサービス生存検証・自動起動メソッド追加

- `ComposeClient.RunningServices(opts ComposeOptions) ([]string, error)` を実装:
  - `docker compose ... ps --services --status running` を実行し、現在稼働中のサービス名一覧を取得します（`--dry-run` 時は起動プレビューのため未起動と仮定）。
- `ComposeClient.EnsureServicesRunning(opts ComposeOptions) error` および `findMissingServices` を実装:
  - 要求されたサービス一覧と稼働中サービス一覧を比較し、すべて稼働中であれば `✔ 共通基盤サービス (...) は既に稼働中です。` と表示してスキップ。
  - 未起動のサービスがある場合は、不足分のみを抽出して `c.Up` で自動起動します。

### 2. `internal/cmd/project.go` の `prepareDependencies` の改善と適用範囲拡大

- `prepareDependencies` 内で `cfg.Core.WorkDir` の存在確認を行った上で、従来の無条件 `Up` 呼び出しを `composeClient.EnsureServicesRunning` に変更しました。
- `projectUpCmd` に加え、`projectStartCmd` および `projectRestartCmd` 実行時にも `prepareDependencies` を呼び出すように変更しました。

### 3. 単体テスト・自動検証の拡充

- [internal/docker/compose_test.go](file:///home/skyou/workspace/devctl/internal/docker/compose_test.go):
  - `TestFindMissingServices`: 全稼働中、一部停止中、全停止中、空スライスの各ケースでの差分抽出ロジックを検証。
  - `TestComposeClient_EnsureServicesRunning`: DryRun 時および空サービス指定時の動作を検証。
- [internal/cmd/project_test.go](file:///home/skyou/workspace/devctl/internal/cmd/project_test.go):
  - `TestPrepareDependencies_WithCoreAndNetwork`: `DependsOn`（Network / Core）を持つプロジェクトに対する `up`, `start`, `restart` の一連の事前検証・起動フローを検証。

### 4. ドキュメントおよび設定例の更新

- [README.md](file:///home/skyou/workspace/devctl/README.md):
  - 主な特徴およびプロジェクト操作セクションに、共通基盤サービスの生存検証・差分自動起動の仕様を追記。
- [configs/config.example.yaml](file:///home/skyou/workspace/devctl/configs/config.example.yaml):
