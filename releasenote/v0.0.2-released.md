## 変更概要

- 実際のローカル開発環境に実在する共通基盤（`toolbox`）および各プロジェクト（`sample`, `catchUper`）のディレクトリ構造・ネットワーク（`internal-network`）に合わせて devctl の仕様を適合。
- `compose_files` 未指定時に `compose.yaml` -> `compose.yml` -> `docker-compose.yaml` -> `docker-compose.yml` を優先度順に探索する Compose ファイル自動検出メカニズムを実装。
- 設定サンプル（`configs/config.example.yaml`）および初期化テンプレート（`internal/config/template.go`）を実環境構成に合わせて更新。
- ソースコード内の構造体・関数コメント（docstring）、Cobra サブコマンドの `Short`/`Long` 説明、フラグヘルプ、実行ログ、設定診断メッセージを日本語話者向けに日本語で統一。
- Compose ファイル検出、デフォルト値解決、作業ディレクトリ判定を網羅する単体テスト（`config_test.go`）を追加。

## 破壊的変更（互換性への影響）

- なし（既存の `config.yaml` で明示的に `compose_files` やネットワーク名が指定されている場合はそちらが優先され、完全な後方互換性を維持しています）。

## 変更詳細

### 1. Compose ファイル名の自動検出（Auto-discovery）

`internal/config/config.go` において、`compose_files` が省略された場合に作業ディレクトリ直下を探索する `detectComposeFiles` を実装しました。

- 探索優先順位:
  1. `compose.yaml`
  2. `compose.yml`
  3. `docker-compose.yaml`
  4. `docker-compose.yml`
- いずれも見つからない場合のフォールバック: `compose.yml`

これにより、`toolbox` や `sample` などの現代的な Compose プロジェクト（`compose.yml` を使用）や、`catchUper` のようなプロジェクト（`docker-compose.yml` を使用）の双方が設定ファイルの記述なしに自動検出されるようになりました。

### 2. 実在環境（toolbox / sample / catchUper）への設定仕様適合

`configs/config.example.yaml` および `internal/config/template.go` を更新し、架空のプロジェクト例から実在する環境定義へ刷新しました。

- **共通基盤 (Core)**:
  - 作業ディレクトリ: `~/workspace/toolbox`
  - Compose ファイル: `compose.yml` (自動検出)
  - サービス: `traefik`, `dbgate`, `dozzle`
- **共通ネットワーク**:
  - 名称: `internal-network` (ドライバ: `bridge`, `attachable: true`)
- **管理対象プロジェクト**:
  - `sample`: `~/workspace/sample` (`compose.yml`)、Core サービス `traefik` に依存
  - `catchUper`: `~/workspace/catchUper` (`docker-compose.yml`)、カスタムタスク `logs`, `backend-sh`, `scraper-sh` を登録

### 3. コードおよび CLI メッセージの日本語化

日本語話者における開発体験および保守性を向上させるため、以下のコンポーネントを日本語化しました。

- **Cobra コマンド**: 全サブコマンド（`root`, `core`, `project`, `network`, `ps`, `config`, `version`）の概要説明、詳細説明、フラグヘルプ、エイリアス説明
- **端末出力 (UI)**: 設定検証ログ、実行中ステップメッセージ、エラーメッセージ、確認警告
- **コードベース**: `cmd/devctl/main.go`、`internal/config/*.go`、`internal/docker/*.go`、`internal/ui/output.go` の各関数・構造体・メソッドの docstring コメント
