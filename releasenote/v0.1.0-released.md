## 変更概要

- Go や make などの開発環境を持たないユーザーでも、単一バイナリを手軽にダウンロードして即座に利用できるようにするため、GitHub Actions による自動リリースワークフロー（`.github/workflows/release.yml`）を構築。
- OS（Linux/macOS）および CPU アーキテクチャ（amd64/arm64）を自動判別して最新バイナリを `~/.local/bin/devctl` に配置するワンライナーインストールスクリプト（`scripts/install.sh`）を導入。
- `README.md` のクイックスタートセクションを刷新し、ワンライナー（`curl -fsSL ... | bash`）および GitHub Releases からの手動ダウンロード手順を最優先で案内するよう改善。

## 破壊的変更（互換性への影響）

- なし（CLI の既存仕様や互換性への影響はありません。バイナリ配布用 CI/CD およびインストーラーの追加です）。

## 変更詳細

### 1. GitHub Actions リリースワークフロー (`.github/workflows/release.yml`)

- バージョンタグ（`v*.*.*`）の push を検知して自動実行。
- マルチプラットフォーム（Linux amd64/arm64, macOS amd64/arm64, Windows amd64）向けに `CGO_ENABLED=0` で静的リンクされた単一バイナリを一括クロスコンパイル。
- バイナリの完全性を担保する SHA256 チェックサムファイル（`checksums.txt`）を自動生成。
- `gh release create` を利用して GitHub Releases へバイナリアセットおよびリリースノートを自動公開。

### 2. ワンライナー・インストーラースクリプト (`scripts/install.sh`)

- `curl -fsSL https://raw.githubusercontent.com/skyou/devctl/main/scripts/install.sh | bash` で実行可能。
- `uname -s` および `uname -m` による OS / アーキテクチャの自動判定。
- GitHub Releases から適切なバイナリを安全にダウンロードし、`~/.local/bin/devctl`（一般ユーザー時）または `/usr/local/bin/devctl`（root 時）へ実行権限（`chmod +x`）付きで配置。
- PATH の疎通確認と、未設定時の `~/.bashrc` / `~/.zshrc` 設定手順を親切にガイド。

### 3. README.md インストールガイドの刷新

- ワンライナーインストールを第一推奨としてドキュメント上部に配置。
- プラットフォーム別のダウンロード対象一覧表（Linux amd64/arm64, macOS Intel/Apple Silicon, Windows）を明記。
