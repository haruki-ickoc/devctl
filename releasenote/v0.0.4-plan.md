## 変更の目的・背景

プロジェクト内のコードスタイルを統一し、エディタ環境や閲覧環境による表示差異を解消するため、リポジトリ内の全ファイル（Go ソースコード、ドキュメント、スクリプト等）におけるタブ（TAB）インデントを廃止し、半角スペースによるインデントへと全面移行・統一する。

## 要求仕様一覧

- [x] 要求項目1: Go ソースコード（`*.go`）の半角スペースインデント化
  - `cmd/` および `internal/` 配下のすべての Go ソースコードにおいて、行頭のタブインデント（`\t`）を半角スペース（1タブ = 半角スペース4文字）へ一括変換する。
- [x] 要求項目2: ドキュメント・スクリプト・設定ファイル内のタブ排除
  - `releasenote/`、`.agents/`、`scripts/` 等に含まれるタブ文字を半角スペースへ置換・統一する。
- [x] 要求項目3: 静的解析およびビルド・テストの通過確認
  - インデント変換後も、`go vet ./...`、`go test ./...`、`make build`、`devctl config check` が正常終了し、構文・動作に影響がないことを確認する。

## 変更対象の想定範囲

ロジック変更は行わず、インデントフォーマットの変換のみを実施する。

- 想定修正ディレクトリ/ファイル:
  - `cmd/devctl/main.go`
  - `internal/cmd/*.go`
  - `internal/config/*.go`
  - `internal/docker/*.go`
  - `internal/ui/*.go`
  - `releasenote/*.md`
  - `.agents/**/*.md`

## 技術的制約および互換性

- Makefile のレシピ行除外: GNU Make の構文仕様上、コマンドレシピ行の先頭には TAB が必須であるため、ビルド破損を防ぐ目的で `Makefile` のレシピ行は TAB のまま維持する。
- インデント幅: Go コードおよびスクリプト類は 1 タブ = 半角スペース 4 文字（4 spaces）を標準とする。
- コードロジックの非変更: コードの処理内容、引数、出力メッセージなどの変更は一切行わない。
