## 変更の目的・背景

GitHub Issue #4（`プロジェクト起動時の共通基盤の生存検証・自動起動`）への対応。
現行（v1.2.0）の `devctl` では、プロジェクトの `depends_on.core` にサービスが指定されている場合、対象サービスが既に稼働中かどうかの生存検証を行わずに毎回無条件で `docker compose up -d` を実行していた。また、`start` や `restart` 実行時には共通基盤の確認が行われないため、PC 再起動後などに `devctl start` を実行すると共通基盤が停止したままで接続エラーとなる課題があった。
本改修では方式A（`depends_on.core` 明示指定型）を採用し、指定された共通基盤サービスの稼働状態（`running`）を事前検証した上で、すべて稼働中であればスキップし、停止中のサービスのみを自動起動する仕組みを実装する。

## 要求仕様一覧

- [x] 要求項目1: `internal/docker/compose.go` へのサービス生存検証・自動起動メソッドの追加
  - `ComposeClient.RunningServices(opts ComposeOptions) ([]string, error)` を追加し、`docker compose ... ps --services --status running` により現在稼働中のサービス名一覧を取得する（`--dry-run` 時は未起動と仮定してシミュレーション表示）。
  - `ComposeClient.EnsureServicesRunning(opts ComposeOptions) error` を追加し、`opts.Services` の稼働状態を検証する:
    - 指定された全サービスが稼働中の場合は、`✔ 共通基盤サービス (...) は既に稼働中です。` と表示して `Up` をスキップする。
    - 未起動（停止中）のサービスがある場合は、不足しているサービスのみを抽出して `Up` で自動起動する。
- [x] 要求項目2: `internal/cmd/project.go` の `prepareDependencies` の改善と適用範囲の拡大
  - `prepareDependencies` 内で `cfg.Core.WorkDir` の設定およびディレクトリ存在確認を行い、無条件の `Up` 呼び出しを `composeClient.EnsureServicesRunning` に置き換える。
  - `projectUpCmd` だけでなく、`projectStartCmd` および `projectRestartCmd` 実行時にも `prepareDependencies` を呼び出し、プロジェクト再開・再起動時にも共通ネットワークおよび共通基盤の生存検証・自動起動が行われるようにする。
- [x] 要求項目3: 単体テスト・自動検証の拡充
  - `internal/docker/compose_test.go` に `RunningServices` / `EnsureServicesRunning` および未起動サービス抽出ロジックの単体テストを追加する。
  - `internal/cmd/project_test.go` に `DependsOn`（Network / Core）を持つプロジェクトでの `up`, `start`, `restart` の DryRun テストを追加する。
  - `go vet ./...` および `go test ./...` を実行し、警告・エラーが 0 件であることを確認する。
- [x] 要求項目4: ドキュメントおよび設定例の同期更新（`documentation.md` 準拠）
  - `README.md` に共通基盤（Core）の生存検証・自動起動の挙動に関する説明を追記する。
  - `configs/config.example.yaml` の `depends_on.core` コメントに生存検証・自動起動の仕様を明記する。

## 技術的制約および互換性

- **破壊的変更の許容**: なし（既存の `config.yaml` の `depends_on` 構文や CLI 引数の互換性を完全に維持すること）。
- **ランナー層の経由**: 外部コマンドの実行は必ず `internal/docker/runner.go`（`RunCommand` / `RunCommandOutput`）を経由し、`--dry-run` に対応させること。
- **外部パッケージの追加**: 原則不可（標準ライブラリおよび既存の Cobra パッケージの範囲で実装すること）。
- **コーディング規約**: インデントは半角スペース4文字を順守し、`CGO_ENABLED=0` による静的リンク性を維持すること。
