## 変更概要

- `config.yaml` の `network` 設定において `subnet` および `gateway` の指定を正式サポート。
- `NetworkManager.Create` および `Ensure` 実行時に、設定された `subnet` / `gateway` を `--subnet` / `--gateway` 引数として `docker network create` に渡すよう拡張。
- `devctl core up`、`devctl project up`、`devctl network create` でのネットワーク担保・作成処理に Subnet / Gateway 設定を反映。
- `configs/config.example.yaml` および `internal/config/template.go` に固定 IP 向けの設定例を追記。
- ルートコマンドの短縮フラグ `-v` (`--verbose`) と衝突して panic を引き起こしていた `down` コマンド（`devctl core down`, `devctl project down`, `devctl down`）の volumes 短縮フラグを `-V`（大文字）に変更し、不具合を解消。

## 破壊的変更（互換性への影響）

- なし
  - `subnet` および `gateway` はオプショナル設定であり、未指定の場合は従来通り Docker デフォルトのサブネット割り当てでネットワークが作成されます。
  - `down` コマンドの短縮フラグ `-v` はこれまで Cobra のフラグ重複検出により実行時 panic を引き起こしていたため、`-V` への変更によって正常に利用できるよう改善されました（ロングオプション `--volumes` も継続して利用可能です）。

## 変更詳細

### 1. 固定 IP（Static IP）利用の正式サポート

コンテナに固定 IP アドレスを割り当てるユースケースに対応するため、共通 Docker ネットワークの Subnet および Gateway を定義・適用可能にしました。

- **設定構造体の拡張 (`internal/config/config.go`)**:
  `NetworkConfig` 構造体に `Subnet` と `Gateway` フィールドを追加。
- **ネットワーク作成処理の改修 (`internal/docker/network.go`)**:
  `NetworkManager.Create` および `NetworkManager.Ensure` のシグネチャを拡張し、指定がある場合に `--subnet <subnet>` および `--gateway <gateway>` をコマンド引数に追加。
- **コマンド層の連携 (`internal/cmd/network.go`, `internal/cmd/core.go`, `internal/cmd/project.go`)**:
  `network create`、`core up`、`project up` / `devctl up` の各実行経路において、`cfg.Network.Subnet` および `cfg.Network.Gateway` を `Ensure` / `Create` に渡すよう修正。
- **設定例とテンプレートの更新 (`configs/config.example.yaml`, `internal/config/template.go`)**:
  設定例としてコメントアウトされた `subnet` / `gateway` のサンプル記述を追加。

### 2. down コマンドのフラグ衝突バグ修正

ルートコマンド（`RootCmd`）でグローバル（Persistent）定義されていた `-v` (`--verbose`) と、各 `down` サブコマンドにローカル定義されていた `-v` (`--volumes`) が衝突し、コマンド実行時やヘルプ表示時に `panic: unable to redefine 'v' shorthand in "down" flagset: it's already used for "volumes" flag` が発生していた問題を解消しました。

- `internal/cmd/core.go`: `coreDownCmd` の volumes 短縮フラグを `-v` から `-V` に変更。
- `internal/cmd/project.go`: `projectDownCmd` および `topDownCmd` の volumes 短縮フラグを `-v` から `-V` に変更。
- これにより、`-v`（詳細ログ）と `-V` / `--volumes`（ボリューム削除）が併用可能になりました。
