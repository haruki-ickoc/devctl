## 変更の目的・背景

初期スキャフォールディング時にローカル環境のユーザー名（`skyou`）が反映されていたリポジトリ名、URL、および Go モジュールパスを、正式なリポジトリ名である `haruki-ickoc/devctl`（`github.com/haruki-ickoc/devctl`）へ全面修正・統一する。

## 要求仕様一覧

- [x] 要求項目1: インストールスクリプトおよびドキュメント内のリポジトリ URL 修正
  - `scripts/install.sh`: `REPO="haruki-ickoc/devctl"` および Usage の URL を修正。
  - `README.md`: ワンライナーインストール URL、Releases URL、`git clone` URL を `haruki-ickoc/devctl` に修正。
- [x] 要求項目2: Go モジュールパスおよび import パスの変更
  - `go.mod`: `module github.com/haruki-ickoc/devctl` に変更。
  - 全 Go ソースコード（`cmd/devctl/main.go`, `internal/cmd/*.go`, `internal/docker/*.go`）内の import パスを置換。
- [x] 要求項目3: ビルド設定（`Makefile`, `.github/workflows/release.yml`）の LDFLAGS 修正
  - `-X` フラグで参照しているシンボルパスを `github.com/haruki-ickoc/devctl/internal/cmd.*` に更新。
