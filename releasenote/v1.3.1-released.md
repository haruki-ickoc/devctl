## 変更概要

- GitHub Issue #12（`共通基盤を docker compose up -d と devctl core up のどちらからでも起動できるか検証する`）への対応。
- 共通基盤（`toolbox/compose.yml`）の `core-network` から `external: true` を廃止し、IPAM（Subnet / Gateway）および `attachable: true` を持つネットワーク定義へ変更することで、`toolbox` 直下での `docker compose up -d` 単体でネットワーク作成からサービス起動まで完結できるように改善。
- `devctl` の `NetworkManager.Create` でネットワークを自動作成する際に Docker Compose 互換ラベル（`com.docker.compose.network` / `com.docker.compose.project`）を付与するよう拡張し、`devctl core up`（または `devctl up <project>` / `devctl network create`）と `docker compose up -d` のどちらから先に起動・操作してもラベル競合やエラーが発生しない完全な相互運用性を確立。

## 破壊的変更（互換性への影響）

- なし（既存の `config.yaml` のスキーマ、CLI コマンド・フラグ、および各プロジェクト側の `compose.yml` における `external: true` 参照の互換性を完全に維持しています）。

## 変更詳細

### 1. 共通基盤（`toolbox/compose.yml`）のネットワーク定義自立化と `.env` 変数連携

- `networks.core-network` に `name: core-network`, `driver: bridge`, `attachable: true`, および `ipam.config`（`subnet: ${SUBNET:-10.10.0.0/24}`, `gateway: ${GATEWAY_IP:-10.10.0.1}`）を定義しました。
- `traefik`, `dbgate`, `dozzle` の固定 IP 設定を `.env` の変数（`${TRAEFIK_IP:-10.10.0.2}`, `${DBGATE_IP:-10.10.0.3}`, `${DOZZLE_IP:-10.10.0.4}`）を参照する形式に統一しました。

```yaml
networks:
    core-network:
        name: core-network
        driver: bridge
        attachable: true
        ipam:
            driver: default
            config:
                - subnet: ${SUBNET:-10.10.0.0/24}
                  gateway: ${GATEWAY_IP:-10.10.0.1}
```

### 2. `devctl` ネットワーク作成時の Docker Compose 互換ラベル付与 (`internal/docker/network.go`, `internal/cmd/root.go`)

- `NetworkManager` に `SetComposeProject` および `buildCreateArgs` を追加し、`docker network create` 実行時に以下のラベルを自動付与するようにしました：
  - `--label com.docker.compose.network=<ネットワーク名>`
  - `--label com.docker.compose.project=<Coreプロジェクト名 (デフォルト: toolbox)>`
- `root.go` の初期化時に `cfg.Core.WorkDir` のベースディレクトリ名（例: `toolbox`）を `networkManager.SetComposeProject` に設定します。

### 3. `docker compose up -d` と `devctl core up` の起動比較・相互運用性まとめ

| 確認項目 | `toolbox/` 直下で `docker compose up -d` | `devctl core up` | 比較・互換性結果 |
| :--- | :--- | :--- | :--- |
| **起動されるサービス** | `traefik`, `dbgate`, `dozzle` | `traefik`, `dbgate`, `dozzle` | 完全一致（Compose プロジェクト名 `toolbox` も一致） |
| **ネットワーク未作成時の挙動** | Compose が `core-network`（`10.10.0.0/24`）を自動作成して起動 | `devctl` が Compose 互換ラベル付きで `core-network` を作成して起動 | 双方ともエラー・警告なく単体起動可能 |
| **環境変数・ボリューム** | `toolbox/.env` を自動読込、`toolbox_*` ボリュームを使用 | `toolbox/.env` を自動読込、`toolbox_*` ボリュームを使用 | 完全一致 |
| **他プロジェクトからの利用** | `external: true` で `core-network` に接続し Traefik / DBGate 利用可 | `external: true` で `core-network` に接続し Traefik / DBGate 利用可 | どちらで起動しても `sample` 等から透過的に利用可能 |
| **相互操作（片方で起動→他方で操作）** | `devctl core ps / logs / restart / down` でそのまま操作可能 | `toolbox/` 直下で `docker compose ps / logs / down` でそのまま操作可能 | ラベル・プロジェクト名・ネットワーク名が一致するため完全互換 |
