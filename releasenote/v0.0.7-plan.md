## 変更の目的・背景

実環境（`~/workspace/sample`）をベースにした実動可能なサンプルプロジェクト構成（Laravel + MySQL + Traefik/DBGate 連携）を `examples/sample/` に追加し、devctl を利用した複数ネットワーク構成（プロジェクト個別サブネットと共通インフラネットワークの共存）のリファレンスをリポジトリ内に提供する。また、Core サービスの DBGate（Web 管理ツール）から各プロジェクトの DB コンテナへアクセスするための接続設定手順とネットワーク仕様を公式ドキュメント（`README.md`）および設定ファイル例（`configs/config.example.yaml`）に明記する。

## 要求仕様一覧

- [x] 要求項目1: `examples/sample/` へのサンプルプロジェクト環境の構築
  - `compose.yml`: `sample-network`（固定 IP / サブネット定義）および `core-network`（共通基盤連携・エイリアス設定）のマルチネットワーク定義、`app` および `db` サービス定義、Traefik ルーティングラベル。
  - `_docker/`: `app/Dockerfile`, `db/Dockerfile`, `.env.example` の配置。
  - 最小限のディレクトリ構造（`public/index.php` 等、Compose 単体や devctl 経由で動作確認できる骨格）。
- [x] 要求項目2: DBGate から各 DB コンテナへのアクセス設定ガイドの追加 (`README.md`)
  - DBGate Web UI（`http://dbgate.localhost`）からの接続設定例（接続タイプ、ホスト名 `sample-db`、ポート `3306`、ユーザー名・パスワード）。
  - 共通ネットワーク（`core-network`）における Docker 内部 DNS エイリアス（`aliases: - sample-db`）による名前解決・疎通の仕組みと前提条件。
- [x] 要求項目3: 設定ファイル例（`configs/config.example.yaml`）およびテンプレートへの補足追記
  - `dbgate` のサービス記述箇所にプロジェクト DB への接続方法に関するコメントを追加。
  - `projects.sample` の `tasks` 定義例に実環境で役立つタスク（migrate, seed, test 等）を反映。
