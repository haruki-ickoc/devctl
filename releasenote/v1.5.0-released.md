## 変更概要

- GitHub Issue #11（`tasksで複数コマンドをリスト定義できるようにする`）への対応。
- プロジェクトの `tasks` 設定（`TaskItem`）において、従来の単一コマンド形式（`description` + `command`）との完全な後方互換性を保ちつつ、タスク名直下へのコマンドリスト定義（`- command-a` / `- command-b`）および `commands` フィールドによる複数コマンド定義に対応。
- `devctl run <project> <task>` 実行時に、リスト定義された複数コマンドを定義順に実行し、途中でコマンドが失敗（非ゼロ終了）した場合は後続コマンドを実行せず即座に停止（Fail-Fast）する制御を実装。

## 破壊的変更（互換性への影響）

- なし（既存の `tasks.<name>.command` による単一コマンド定義や CLI 引数の互換性を完全に維持しています）。

## 変更詳細

### 1. `TaskItem` の複数コマンド YAML パース対応 (`internal/config/config.go`)

- `TaskItem` に `Commands []string`、`GetCommands() []string`、`Summary() string`、およびカスタム YAML アンマーシャラ `UnmarshalYAML(value *yaml.Node) error` を実装しました。
- 以下の YAML 記法をすべて透過的にパースできます：
  1. **直リスト形式**:
     ```yaml
     tasks:
       setup:
         - "docker compose exec app composer install"
         - "docker compose exec app php artisan migrate"
         - "docker compose exec app php artisan db:seed"
     ```
  2. **`description` + `commands`（または `command` リスト）形式**:
     ```yaml
     tasks:
       test-all:
         description: "Unit / Feature テストを順次実行"
         commands:
           - "docker compose exec -e APP_ENV=testing app php artisan test --testsuite=Unit"
           - "docker compose exec -e APP_ENV=testing app php artisan test --testsuite=Feature"
     ```
  3. **既存の単一コマンド形式**:
     ```yaml
     tasks:
       migrate:
         description: "データベースマイグレーションの実行"
         command: "docker compose exec app php artisan migrate"
     ```

### 2. 複数コマンドの順次実行と Fail-Fast 制御 (`internal/docker/compose.go`, `internal/cmd/project.go`)

- `ComposeClient.RunShellTasks(workDir string, commands []string) error` を追加しました。
- 複数コマンド実行時は `[1/3] カスタムタスクを実行中: ...` のようにステップ進捗を表示し、`runner.RunShell`（`sh -c`）を経由して各コマンドを実行します（引数や環境変数のインライン指定および `--dry-run` に対応）。
- いずれかのステップがエラー（非ゼロ終了）となった時点で即座に中断し、失敗したステップ番号・コマンドを含むエラーを呼び出し元へ返却します。

### 3. 単体テストおよびドキュメントの更新

- `internal/config/config_test.go`: `TestTaskItem_UnmarshalYAML` を追加し、各 YAML 記法のパース結果を検証。
- `internal/docker/compose_test.go`: `TestComposeClient_RunShellTasks` を追加し、定義順実行および途中失敗時の Fail-Fast 動作を検証。
- `internal/cmd/project_test.go`: `TestRunCmd_MultiCommandExecution` を追加し、`devctl run` での単一・複数コマンド実行および異常系を検証。
- `README.md`、`configs/config.example.yaml`、`internal/config/template.go` に複数コマンドタスクの記述例と仕様を追記。
